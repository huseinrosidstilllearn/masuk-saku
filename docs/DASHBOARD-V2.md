# Dashboard V2 — referensi baru

Permintaan pengguna27September2026: mengikuti [reel Dashboard V2 oleh code.xr](https://www.instagram.com/reel/Ddf-7oiz126/), melepas batas satu warna hijau, dan meringankan animasi navigasi. Ini menggantikan preferensi green-only/Billow sebelumnya untuk visual aplikasi. Web app, pencatatan keluarga dan konfirmasi manusia tetap menjadi batas produk.

Web fetch Instagram dibatasi; browser publik berhasil membuka reel tanpa login, setelah menutup prompt pendaftaran. Frame sekitar0.5/2.5/4.5detik diperiksa, termasuk dashboard pekerjaan dengan lime/orange/peach, dashboard finansial dengan kanvas abu muda/kartu putih/saldo gelap/aksen coral-orange, dan layar kalender. Halaman juga menyebut React/CSS/Framer Motion; source tidak diperoleh dan tidak dibutuhkan untuk implementasi. Frame screenshot disimpan di work/ hanya untuk inspeksi, tidak menjadi aset aplikasi. Tidak menyalin logo, foto, source, kode pada video, ilustrasi, angka atau data author.

Acuan utama adalah dashboard finansial karena sesuai cash management: empat ringkasan berwarna di atas; grafik arus uang putih di kiri dan saldo gelap dengan tiga aksi ledger di kanan; transaksi terbaru setelah Quick Add; anggaran/kategori/dompet/target di bawah. Lime, peach/pink, coral-orange dan lavender membedakan kartu. Nilai dan grafik memakai agregasi aktual IDR, bukan portfolio/trading/investasi pada contoh. Titik dan garis grafik tidak menambah smoothing atau pertumbuhan palsu. Warna tidak menjadi satu-satunya penjelas transaksi atau status.

Desktop memiliki rail putih72px dengan ikon Lucide, nama aksesibel dan tooltip. Ponsel mempertahankan navigasi bawah berlabel dan capture dock di atasnya. Tata letak berpindah dari empat menjadi dua kolom ringkasan, saldo di atas grafik pada<=800px. Shortcut anggaran/target pada kartu kini terlihat. Form, dompet, kalender WIB dan halaman masuk mengikuti palet baru; DM Sans tebal tetap.

Implementasi utama: src/dashboard-v2.css, diimpor sesudah date-time.css dan sebelum motion.css. App.tsx memisahkan balance-pocket/cashflow-panel dalam parent balance-card; pemisahan visual tidak mengubah data/RPC. Alias lama --green sekarang menunjuk primary netral untuk kompatibilitas komponen; green-only sudah tidak berlaku. Billow layer menyediakan struktur Welcome yang sudah terhubung Auth, kemudian warna/component surface dioverride V2. Tampilan merupakan adaptasi isi Masuk Saku dari referensi yang diamati, bukan klaim pixel-identical terhadap beberapa dashboard berbeda di video.

Navigasi memakai recipe08 Transitions.dev yang disederhanakan menjadi opacity120ms; jarak0, filter:none, transform:none, will-change:auto pada incoming page. Hanya satu halaman keuangan dirender; masking dan pergantian scope tetap langsung. Tidak ada dependency Framer Motion, efek spring, animasi keluar snapshot atau blur layar penuh. Semua native modal/FAQ/notice dan prefers-reduced-motion mengikuti fondasi yang sudah ada. Lihat [MOTION](MOTION.md).

Pemeriksaan layout pada320/768/1024/1440px menegaskan kartu ringkasan di atas grafik/saldo, posisi saldo kanan desktop/atas ponsel, label navigasi ponsel terlihat dan tidak overflow. Tes motion memeriksa properti aktual opacity120ms/no filter/no transform/no permanent promotion, rapid navigation, focus dan privacy. Hasil final/release tersedia di [VERIFICATION](VERIFICATION.md). Browser tests memakai demo lokal; hosted authenticated pilot tetap terpisah.
